# HomeWizard Link app
Old devices, new possibilities! Link your Link to Homey and take your smart home to the next level. 

The app currently supports:
- CO detector: CO alarm, battery alarm
- Color light bulb: on/off, dim, RGB, white temperature
- Door sensor: Contact alarm, tamper alarm, battery alarm
- Multi White light bulb: on/off, dim, white temperature
- Smoke detector: smoke alarm, battery alarm
- Thermometer: temperature, humidity
- Water leakage detector: water alarm, battery alarm

# Device support
Since I only have the Color bulb and the door sensor, I need your help to get the other devices supported. If you have any of the following devices:

- Wall switch converter
- Siren
- Socket
- Plug-in dimmer

Or any other device that works with the HomeWizard Link app, please let me know in the [forum topic](https://community.homey.app/t/145076) so that I can add support for it.
